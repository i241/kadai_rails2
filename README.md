## 概要
Ruby on Rails を用いて作成したWebアプリケーションです。  
空きスペースシェアアプリを作成しました。  
ユーザー登録・ログイン機能を実装し、スペースの投稿から予約まで一連の流れをCRUDベースで構築しました。

## 機能
- ユーザー新規登録 / ログイン / ログアウト
- マイページ表示
- 空きスペースの投稿（作成）
- 空きスペース一覧表示 / 詳細表示
- 空きスペースの予約機能

## 技術スタック
- Ruby
- Ruby on Rails
- SQLite3

## 学んだこと
- MVCの役割分担
- コントローラとモデルの責務
- Railsのディレクトリ構成
- Gemの導入
